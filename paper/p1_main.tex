\section*{Data and code availability}
All source, configurations, experiment manifests and figure-generation
scripts are available at \url{https://github.com/SharathSPhD/CINS}. Every
figure in this paper is regenerable from an archived run manifest recording
the configuration hash, git SHA and random seed; the procedure is stated in
Appendix~\ref{app:repro}. The flow solver is \texttt{mfoil}, used unmodified
as a vendored dependency.
